Paleta — веб-приложение для генерации, редактирования, сохранения и экспорта цветовых палитр. Создавайте палитры из загруженных изображений (извлечение доминирующих цветов через KMeans) или генерируйте случайные, а затем управляйте ими в личном аккаунте.

Проект ориентирован на дизайнеров, frontend-разработчиков и всех, кто работает с цветом и хочет быстро переходить от изображения к готовым HEX-кодам.

## Зачем Paleta

### Цель

Удобный браузерный инструмент, который превращает визуальные референсы в готовые цветовые палитры — с мобильным Android-приложением для работы на ходу.

### Какую проблему решает

- Ручной подбор цветов с изображений занимает много времени.
- Экспорт палитр в форматы дизайн-инструментов часто требует сторонних утилит.
- Без аккаунта и базы данных сложно хранить и систематизировать палитры.

### Чем отличается

- **Два режима генерации**: по изображению (KMeans) и случайная палитра.
- **Встроенное редактирование**: color picker + HEX + копирование в буфер.
- **Управление палитрами**: сохранение, переименование, удаление, фильтры, сортировка.
- **6 форматов экспорта**: JSON, GPL, ASE, CSV, PNG, ACO — для разработчиков и дизайнеров.
- **Mobile API**: полноценный REST API для [Paleta Mobile](https://github.com/diamko/Paleta_mobile_app).
- **Восстановление пароля**: верификация по email с ограничением попыток.

## Ключевые функции

| Категория | Возможности |
| --- | --- |
| **Генерация** | Извлечение доминирующих цветов из изображения (KMeans), случайная генерация |
| **Редактирование** | Color picker, ввод HEX, пересчёт с другим количеством цветов |
| **Экспорт** | JSON, GPL, ASE, CSV, PNG, ACO |
| **Библиотека** | Личная библиотека с поиском, фильтрацией по кол-ву цветов, сортировкой |
| **Авторизация** | Регистрация, вход, выход, сброс пароля по email |
| **Загрузки** | Drag-and-drop загрузка, недавние загрузки (за 7 дней) |
| **Мобильное API** | REST API для Android-клиента (авторизация, палитры, генерация, экспорт) |
| **i18n** | Русский и английский интерфейс |

## Технологии

| Слой | Технология |
| --- | --- |

## Как это работает

1. Пользователь загружает изображение (или генерирует случайную палитру).
2. Бэкенд уменьшает изображение и запускает кластеризацию KMeans.
3. Доминирующие RGB-цвета преобразуются в HEX.
4. Пользователь может редактировать, копировать, экспортировать или сохранить палитру.
5. Сохранённые палитры привязываются к аккаунту и доступны в разделе «Мои палитры».

## Установка и настройка

### Требования

- `git`
- `Python 3.10+` (рекомендуется `3.12`)
- `pip`
- `PostgreSQL` (или Docker)

### 1) Клонирование репозитория

```bash
git clone https://github.com/diamko/Paleta_web_app.git
cd Paleta_web_app
```

### 2) Создание и активация виртуального окружения

> Используйте `.venv` (с точкой), а не `venv`. На Windows — `python` вместо `python3`.

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3) Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4) Инициализация базы данных (первый запуск)

Быстрый запуск PostgreSQL через Docker:

```bash
docker run --name paleta-postgres \
  -e POSTGRES_DB=paleta \
  -e POSTGRES_USER=paleta \
  -e POSTGRES_PASSWORD=paleta \
  -p 5432:5432 \
  -d postgres:latest
```

Создание таблиц:

```bash
python3 -c "from app import app; from extensions import db; import models; app.app_context().push(); db.create_all()"
```

URL базы данных по умолчанию:

| Окружение | URL |
| --- | --- |
| Development | `postgresql+psycopg://paleta:paleta@localhost:5432/paleta` |
| Production | `postgresql+psycopg://paleta:paleta@db:5432/paleta` |

## Конфигурация

Основные параметры — в `config.py`. Переопределяются через переменные окружения:

### Основные

| Переменная | Описание | По умолчанию |
| --- | --- | --- |
| `SECRET_KEY` | Секрет сессии (обязателен в production) | Авто в dev |
| `DATABASE_URL` | Строка подключения PostgreSQL | Локальная PostgreSQL |
| `FLASK_ENV` | `development` или `production` | `development` |

### Безопасность

| Переменная | Описание | По умолчанию |
| --- | --- | --- |
| `SESSION_COOKIE_SECURE` | Только HTTPS куки | `true` в prod |
| `CORS_ENABLED` | Включить CORS | `false` |
| `CORS_ORIGINS` | Разрешённые origin (через запятую) | — |

### Обработка изображений

| Переменная | Описание | По умолчанию |
| --- | --- | --- |
| `MAX_IMAGE_PIXELS` | Макс. разрешение изображения (пиксели) | `20000000` |
| `MIN_COLOR_COUNT` | Мин. цветов в палитре | `3` |
| `MAX_COLOR_COUNT` | Макс. цветов в палитре | `15` |

### Восстановление пароля (email)

| Переменная | Описание | По умолчанию |
| --- | --- | --- |
| `SMTP_HOST` | Хост SMTP-сервера | — |
| `SMTP_PORT` | Порт SMTP | `587` |
| `SMTP_USER` | Имя пользователя SMTP | — |
| `SMTP_PASSWORD` | Пароль SMTP | — |
| `SMTP_FROM` | Email отправителя | — |
| `SMTP_USE_TLS` | Использовать STARTTLS | `true` |
| `SMTP_USE_SSL` | Использовать SSL (взаимоисключает TLS) | `false` |
| `PASSWORD_RESET_CODE_TTL_MINUTES` | Время жизни кода | `15` |
| `PASSWORD_RESET_MAX_ATTEMPTS` | Макс. попыток ввода кода | `5` |

### Прочие значения

- `UPLOAD_FOLDER = static/uploads`
- `MAX_CONTENT_LENGTH = 16 MB`
- Разрешённые расширения: `png`, `jpg`, `jpeg`, `webp`

## Как пользоваться

### Гостевой режим (без регистрации)

- Извлечение палитры из изображения
- Генерация случайных палитр
- Редактирование и копирование HEX-кодов
- Экспорт палитр в любой формат

### Режим авторизованного пользователя

Дополнительно:

- Сохранение палитр в личную библиотеку
- Переименование и удаление палитр
- Поиск, фильтрация и сортировка в «Моих палитрах»
- Повторное использование недавних загрузок (за 7 дней)
- Восстановление пароля через email

### Базовый сценарий

1. Откройте главную страницу → загрузите изображение или перейдите к генератору.
2. Выберите количество цветов и запустите генерацию/пересчёт.
3. При необходимости отредактируйте цвета.
4. Экспортируйте или сохраните палитру.
5. Управляйте палитрами в разделе «Мои палитры».

## Web API эндпоинты

| Метод | Эндпоинт | Описание |
| --- | --- | --- |
| `POST` | `/api/upload` | Загрузка изображения и извлечение палитры |
| `POST` | `/api/palettes/save` | Сохранение палитры (нужен вход) |
| `POST` | `/api/palettes/rename/<id>` | Переименование палитры (нужен вход) |
| `DELETE` | `/api/palettes/delete/<id>` | Удаление палитры (нужен вход) |
| `POST` | `/api/export?format=<type>` | Экспорт палитры (json, gpl, ase, csv, png, aco) |

## Mobile API эндпоинты

REST API для Android-клиента [Paleta Mobile](https://github.com/diamko/Paleta_mobile_app). Все эндпоинты с префиксом `/api/mobile/v1`.

### Авторизация

| Метод | Эндпоинт | Описание |
| --- | --- | --- |
| `POST` | `/auth/login` | Вход, возвращает access + refresh токены |
| `POST` | `/auth/register` | Регистрация нового пользователя |
| `POST` | `/auth/refresh` | Обновление access-токена |
| `POST` | `/auth/logout` | Отзыв токенов |
| `GET` | `/auth/me` | Получение профиля текущего пользователя |
| `POST` | `/auth/password/forgot` | Запрос кода восстановления пароля (email) |
| `POST` | `/auth/password/reset` | Сброс пароля по коду |

### Профиль

| Метод | Эндпоинт | Описание |
| --- | --- | --- |
| `GET` | `/profile` | Получение профиля |
| `PATCH` | `/profile` | Обновление имени / email |
| `POST` | `/profile/password/send-code` | Отправка кода для смены пароля |
| `POST` | `/profile/password/change` | Смена пароля по коду |

### Палитры

| Метод | Эндпоинт | Описание |
| --- | --- | --- |
| `GET` | `/palettes` | Список палитр (поиск, сортировка, фильтр) |
| `POST` | `/palettes` | Создание палитры |
| `PATCH` | `/palettes/<id>` | Переименование палитры |
| `DELETE` | `/palettes/<id>` | Удаление палитры |
| `POST` | `/palettes/<id>/save` | Обновление цветов палитры |

### Генерация и экспорт

| Метод | Эндпоинт | Описание |
| --- | --- | --- |
| `POST` | `/generate/image` | Извлечение цветов из загруженного изображения |
| `POST` | `/generate/random` | Генерация случайной палитры |
| `GET` | `/uploads/recent` | Недавние загрузки (за 7 дней) |
| `GET` | `/uploads/<filename>` | Выдача загруженного изображения |
| `POST` | `/export` | Экспорт палитры в файл |
